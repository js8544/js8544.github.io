# jinshang.ai

Personal site of Jin Shang, built with Jekyll and published by GitHub Pages from `master`.

- Posts live in `_posts/blog/` and are served at `/blog/<slug>/`.
- Add `hidden: true` to a post's front matter to keep its page but drop it from lists, the feed, and search.
- Add `lang: zh` to Chinese posts and `mathjax: true` to posts that need math.

Preview locally:

    bundle install
    bundle exec jekyll serve
